# 🛍️ NovaMart Analytics

### Interactive Retail Sales & Customer Analytics Dashboard

NovaMart Analytics is a **Pandas + Streamlit + Plotly** dashboard that transforms raw retail datasets into interactive business insights.

The project combines **customers, orders, and products** data to analyze sales, profitability, products, customers, discounts, returns, delivery performance, and business trends.

---

## 🚀 Features

* 📊 Executive business dashboard
* 💰 Revenue & profit analysis
* 🛒 Product & category performance
* 📅 Monthly sales trends
* 🌍 State & city analysis
* 📦 Sales channel analysis
* ↩️ Returns analysis
* 🚚 Delivery & rating analysis
* 🏷️ Discount effectiveness
* 👥 Customer analytics
* 🎯 RFM customer segmentation
* 📋 Interactive detailed data
* ⬇️ Filtered CSV download

---

## 🗂️ Dataset

The application combines three datasets:

```text
customers.csv
orders.csv
products.csv
```

They are merged using:

```text
customer_id
product_id
```

This creates a unified dataset for end-to-end business analysis.

## ⚙️ Installation

Clone the repository:

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd novamart_project
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python -m streamlit run app.py
```

Open:

```text
http://localhost:8501
```
